## Check before making GPX

- **S05:** the source is unclear on where it ends. Its table and stop list do not clearly agree.
- **S03 / S04:** described as the same loop in opposite directions, but the key areas differ. Make separate GPX files.
- **Route changes:** a realignment was agreed in principle but still needed ministry approval ([Sabah News, 31 Oct 2026](https://sabahnews.com.my/tiada-kompromi-terhadap-pengusaha-pemandu-kenderaan-berat-langgar-syarat-lesen-phoong/)).
